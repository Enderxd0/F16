# Security Policy

## Supported Versions

Currently, only the latest version available in the main branch is supported
with security updates. Older versions are not maintained.

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public issue.

Instead, report it privately by contacting the repository owner through
GitHub or by opening a private security advisory if available.

You can expect a response within 3-7 days.

Please include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if possible)

We appreciate responsible disclosure.
